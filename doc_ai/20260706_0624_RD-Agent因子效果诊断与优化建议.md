## 1. 执行摘要（TL;DR）

本轮（Loop_0）RD-Agent 生成并回测了 4 个因子：`5_day_momentum`、`10_day_momentum`、`10_day_high_low_ratio`、`5_day_average_true_range_normalized`。结论是：

> **这 4 个因子只是"执行跑通"（代码能跑、产出 `result.h5`），但在效果评估中全面劣于 SOTA 基线，`decision=False`，未进入因子库。** 它们**不是"成功的因子"**。

| 关键指标 | 本轮 Current | SOTA 基线 | 差距 |
|---|---:|---:|---:|
| IC | 0.02991 | 0.03107 | −3.7% |
| Rank IC | 0.03181 | 0.03351 | −5.1% |
| ICIR | 0.23175 | 0.26056 | −11.1% |

IC≈0.03 属于"弱有效"区间（行业经验：IC>0.05 才算优秀因子），且本轮在所有维度上都落后于已有 SOTA。

**四大根因（详见第 8 节）：**
1. **因子维度单一**：4 个因子全是纯价格类（动量+振幅/ATR），缺乏量价联合、回归残差等高信息维度；
2. **信号样本外衰减**：IC 按年单调下降（2017 的 0.0451 → 2020 的 0.0178，衰减约 60%），日 IC 自相关≈0，末期信号接近失效；
3. **无中性化 + 高换手**：回测无 industry/size neutralize，最大回撤（−32.4%）几乎等于基准，alpha 没起规避作用；换手高导致成本吃掉约 2/3 的信息比；
4. **与 SOTA 高度共线**：本轮因子与 SOTA 的 20 个 Alpha158 因子在信号维度上重叠，难以突破 RD-Agent 的 0.99 去重阈值——这是 `decision=False` 的深层原因。

## 2. 运行背景与评估口径

### 2.1 RD-Agent 因子研发循环

RD-Agent 的 qlib 因子场景按 5 个 step 循环迭代：

```
direct_exp_gen (生成假设 + 因子定义)
      → coding (CoSTEER 多轮进化生成 factor.py)
      → running (Qlib 回测，产出 IC 等指标)
      → feedback (LLM 比较 current vs SOTA，输出 decision)
      → record (写入 trace，更新历史)
```

本轮只完成了 **Loop_0**（1 轮）。SOTA 基线来自 trace 中 `decision=True` 的历史最佳实验，是 20 个 Alpha158 因子的组合。

### 2.2 评估口径（重要，避免误读）

| 维度 | 配置 | 说明 |
|---|---|---|
| 模型 | `LGBModel`（LightGBM） | lr=0.2, max_depth=8, num_leaves=210, lambda_l1=205.7, lambda_l2=580.98 |
| Label | `Ref($close,-2)/Ref($close,-1)-1` | **T+1 买入价到 T+2 卖出价**的 next-day forward return |
| 数据时段 | 2008-01-01 ~ 2020-08-01 | train 2008-2014, valid 2015-2016, **test 2017-01-01~2020-08-01（约 3.6 年）** |
| 市场/基准 | csi300 / SH000300（沪深300） | |
| 标签预处理 | `DropnaLabel` → `CSZScoreNorm` | **仅截面 z-score，无 industry / size / risk neutralize** |
| 数据加载 | Alpha158 因子集 + `combined_factors_df.parquet`（本轮 4 因子）并列喂入 | |
| 策略 | `TopkDropoutStrategy` | topk=50（持仓 50 只）, n_drop=5 |
| 交易成本 | open_cost=0.0005, close_cost=0.0015, min_cost=5 | 单边约 5~15 bp |

**IC 口径（关键）**：报告中的 IC / Rank IC / ICIR 是 qlib `SigAnaRecord` 计算的**组合 IC**——即"本轮 4 因子 + Alpha158 共同喂入一个 LightGBM，输出单一预测信号"后，该信号与真实 next-day 收益的截面相关性。**它不是单因子 IC**。`develop` pkl 中 `sub_results` 为空字典（`len=0`），系统**未对 4 个因子分别计算 IC**，因此无法从现有产物做单因子归因。

### 4.2 逐日 IC 时序分析（核心诊断）

逐日 IC 存在于 `mlruns/.../artifacts/sig_analysis/ic.pkl`（868 个有效交易日）和 `ric.pkl`（Rank IC）。

**Daily Pearson IC（n=868）：**

| 统计量 | 数值 |
|---|---:|
| 均值 | 0.02991 |
| 标准差 | 0.12906 |
| 中位数 | 0.02702 |
| IC > 0 占比 | **59.91%**（520/868） |
| IC > 0.02 占比 | 53.00% |
| IC < −0.02 占比 | 34.56% |
| 最小值 / 最大值 | −0.3659 / +0.4442 |
| 偏度 / 峰度 | 0.019 / 0.055（近正态） |
| 自相关 lag1 / lag5 / lag20 | 0.0054 / 0.0170 / 0.0046 |

**关键诊断点：**

1. **IC > 0 占比仅 59.9%**：仅略高于 50% 的随机基线，意味着近 40% 的交易日因子方向是错的；
2. **自相关近 0**（lag1=0.005）：IC 序列几乎没有日间持续性，**信号不稳定、不可预测**；
3. **按年单调衰减（最重要）**：

   | 年份 | IC 均值 | IC std | 年化 ICIR | Rank IC 均值 |
   |---|---:|---:|---:|---:|
   | 2017 | **0.04511** | 0.12460 | 0.3620 | 0.0443 |
   | 2018 | 0.02965 | 0.14612 | 0.2029 | 0.0330 |
   | 2019 | 0.02180 | 0.11548 | 0.1888 | 0.0205 |
   | 2020 | **0.01783** | 0.12606 | 0.1415 | 0.0273 |

   IC 从 2017 的 **0.0451 单调衰减到 2020 的 0.0178，衰减约 60%**。60 日滚动 IC 从开头的 0.038 滑到末期的 **0.005（接近 0）**——**alpha 在样本外持续失效**。这是本轮因子最本质的问题：动量类因子在 A 股 2017-2020 期间呈现明显的"动量衰减"甚至反转特征，简单价格动量已不再是稳定 alpha 源。

### 4.3 单因子 IC 缺失的影响

如 2.2 节所述，`sub_results` 为空，**无法从现有产物拆出"5_day_momentum 单独 IC"等单因子贡献**。这带来两个后果：
- 无法判断 4 个因子里是哪一个拖后腿（直觉上：5 日/10 日动量高度共线，且都是衰减信号，互相重复；ATR/振幅类贡献可能更弱）；
- 若要做归因，需要单独把每个因子喂入相同的回测管线重跑（不在本报告范围内，属后续可执行项）。

## 5. 回测超额收益维度诊断

逐日组合净值来自 `ret.pkl`（871 行，2017-01-03 ~ 2020-07-31），`return` 列为组合当日收益率，`bench` 为沪深300 当日收益率。

### 5.1 三口径收益对比

| 口径 | 总收益 | 年化收益 | 年化波动 | Sharpe/IR | 最大回撤 |
|---|---:|---:|---:|---:|---:|
| 组合（绝对） | +75.55% | 17.68% | 23.52% | 0.752 | −32.42% |
| 基准（沪深300） | +41.84% | 10.64% | 19.52% | 0.545 | −32.46% |
| **超额（无成本）** | +25.30% | **6.74%** | 10.16% | **0.664** | −14.02% |
| **超额（含成本，qlib_res）** | — | **2.15%** | — | **0.218** | −17.08% |

### 5.2 成本侵蚀：吃掉约 2/3 的信息比

- 无成本超额 IR **0.664** → 含成本 IR **0.218**，**信息比下降约 67%**；
- 无成本年化超额 **6.65%** → 含成本 **2.15%**，**收益下降约 68%**；
- 对比 SOTA：SOTA 无成本 IR 0.954 / 含成本 IR 0.442，**成本侵蚀比例（54%）低于本轮（67%）**，说明**本轮组合的换手更高、对成本更敏感**。

### 5.3 成本敏感根因

1. **label 是 next-day（T+1→T+2）**：预测目标是极短期收益，天然驱动高频换仓；
2. **topk=50 / n_drop=5**：每日强制换掉 5/50 = 10% 持仓，双边换手率高；
3. **动量因子本身换手高**：价格动量每日排序变化大，叠加 n_drop 机制放大换手。

> 注：组合绝对收益 17.68% 看似不低，但其中绝大部分来自市场 beta（基准年化 10.64% + 小盘股弹性），**真正来自因子的超额收益（含成本）只有 2.15%**，这才是因子价值的真实度量。

## 7. 因子多样性 / 去相关维度诊断

### 7.1 本轮 4 因子：全部纯价格类

| 因子 | 表达式 | 维度 |
|---|---|---|
| `5_day_momentum` | (close_t − close_{t-5}) / close_{t-5} | 纯价格·动量 |
| `10_day_momentum` | (close_t − close_{t-10}) / close_{t-10} | 纯价格·动量 |
| `10_day_high_low_ratio` | (max(high,10) / min(low,10)) − 1 | 纯价格·振幅 |
| `5_day_ATR_normalized` | mean(TR,5) / close | 纯价格·波动 |

**4 个因子无一例外都是纯价格类**，不涉及成交量、不涉及回归残差、不涉及横截面相对位置。其中两个动量因子（5 日、10 日）高度共线，本质上信息重复。

### 7.2 SOTA 基线 20 因子：量价联合 + 回归残差为主

SOTA 实验的 `base_features`（20 个 Alpha158 风格表达式）：

| 因子 | 表达式 | 维度 |
|---|---|---|
| RESI5 | `Resi($close, 5)/$close` | 回归残差 |
| WVMA5 | `Std(Abs($close/Ref($close,1)-1)*$volume, 5)/(...)` | **量价联合** |
| RSQR5 | `Rsquare($close, 5)` | 回归拟合度 |
| KLEN | `($high-$low)/$open` | K 线形态 |
| RSQR10 | `Rsquare($close, 10)` | 回归拟合度 |
| CORR5 | `Corr($close, Log($volume+1), 5)` | **量价相关** |
| CORD5 | `Corr($close/Ref($close,1), Log($volume/Ref($volume,1)+1), 5)` | **量价差分相关** |
| CORR10 | `Corr($close, Log($volume+1), 10)` | **量价相关** |
| ROC60 | `Ref($close, 60)/$close` | 长端动量 |
| RESI10 | `Resi($close, 10)/$close` | 回归残差 |
| VSTD5 | `Std($volume, 5)/($volume+1e-12)` | **量能波动** |
| RSQR60 | `Rsquare($close, 60)` | 回归拟合度 |
| CORR60 | `Corr($close, Log($volume+1), 60)` | **量价相关** |
| WVMA60 | `Std(Abs($close/Ref($close,1)-1)*$volume, 60)/(...)` | **量价联合** |
| STD5 | `Std($close, 5)/$close` | 价格波动 |
| RSQR20 | `Rsquare($close, 20)` | 回归拟合度 |
| CORD60 | `Corr($close/Ref($close,1), Log($volume/Ref($volume,1)+1), 60)` | **量价差分相关** |
| CORD10 | `Corr($close/Ref($close,1), Log($volume/Ref($volume,1)+1), 10)` | **量价差分相关** |
| CORR20 | `Corr($close, Log($volume+1), 20)` | **量价相关** |
| KLOW | `(Less($open, $close)-$low)/$open` | K 线形态 |

20 个因子里，**量价联合类（CORR/CORD/WVMA/VSTD）占 9 个，回归残差/拟合类（RESI/RSQR）占 7 个**——这两类正是本轮 4 因子**完全缺失**的维度。

### 7.3 结构性结论：为什么 decision=False

RD-Agent 的 `QlibFactorRunner.calculate_information_coefficient` 会对新因子与 SOTA 已有因子做两两 Pearson 相关（按 datetime 分组取均值），**相关系数 > 0.99 即视为重复因子并丢弃**。本轮 4 因子虽然未必与 SOTA 单个因子相关到 0.99，但：

- 它们提供的信号维度（短期价格动量/波动）**已被 SOTA 中的 STD5、ROC60、KLEN、KLOW 等因子大量覆盖**；
- 增量信息不足以让"本轮因子 + SOTA"的组合击败"纯 SOTA"——回测结果（IC 0.0299 < 0.0311）证明了这一点；
- LLM feedback 的判断（`decision=False`）本质就是："加入这些因子后整体效果不升反降，不采纳"。

**这正是本轮最深层的问题**：不是因子"算错了"，而是因子"维度撞车"，对已有因子库没有增量贡献。

## 9. 优化建议（按用户关心的 4 维度）

### 9.1 提升 IC（信息系数）

**方向：补齐缺失的因子维度，引入量价联合与回归残差类。**

| 建议因子类别 | 示例（qlib 表达式） | 为什么有效 |
|---|---|---|
| **量价联合** | `Corr($close, Log($volume+1), N)`（N=5/10/20） | SOTA 中此类因子占比最高，已被验证 |
| **量价差分相关** | `Corr($close/Ref($close,1), Log($volume/Ref($volume,1)+1), N)` | 捕捉"价涨量增/价跌量缩" |
| **回归残差** | `Resi($close, N)/$close` | 去趋势后的均值回归信号 |
| **回归拟合度** | `Rsquare($close, N)` | 趋势确定性 |
| **风险调整动量** | `momentum_5d / Std($close, 5)` | 单位波动下的动量，比裸动量更稳 |
| **长端动量 + 短端反转** | `Ref($close,60)/$close` 与 `Ref($close,5)/$close` 反向组合 | 对冲动量衰减（见 4.2 节） |

**窗口拓展**：本轮只用 5/10 日，建议增加 20/60 日窗口，覆盖不同周期。

### 9.2 提升回测超额收益

**方向：降低换手、控制成本。**

- **调大 topk / 减小 n_drop**：如 topk=50→80, n_drop=5→3，降低日换手率；
- **换 label 为 longer-horizon**：如 `Ref($close,-5)/Ref($close,-1)-1`（5 日 forward return），降低天然换仓频率；
- **成本敏感性测试**：对比 open/close_cost 在 0 与实际下的 IR 差距，作为因子筛选标准（剔除高换手低纯 alpha 的因子）。

### 9.3 改善风险控制

**方向：加入中性化与风险约束。**

- **Industry / Size neutralize**：在 `learn_processors` 中加入 `CSRankNorm` + 行业中性化（qlib 的 `RobustZScoreNorm` + 板块分组），剥离行业 beta；
- **跟踪误差约束**：控制组合相对基准的行业/市值偏离；
- **回撤约束**：在策略层加入止损或波动率目标（vol targeting）；
- **预期效果**：参考 6.1 节，中性化后最大回撤有望从 −32% 显著下降（剥离市场 beta），Sharpe 提升。

### 9.4 提升因子多样性 / 突破去重阈值

**方向：探索与 SOTA 正交的新维度。**

当前 SOTA 已覆盖"量价相关 + 回归残差 + K 线形态"，应主动探索其**未覆盖**的维度：

| 新维度 | 示例 | 与 SOTA 正交性 |
|---|---|---|
| **隔夜收益** | `Open_t / Close_{t-1} - 1`（需 $open） | 高（SOTA 无此类） |
| **横截面离散度** | 个股收益减行业均值 | 高 |
| **成交额分布** | 当日成交额 / 过去 N 日均值 | 中（VSTD5 相关） |
| **资金流代理** | `(Close-Open)/(High-Low) * Volume` | 高 |
| **流动性** | `Mean($volume, N) / $market_value` | 高 |
| **波动率结构** | 已实现波动 vs GARCH 预测波动之差 | 高 |

**目标**：让新因子与 SOTA 任一因子的相关性显著低于 0.99，从而**真正进入因子库**（这是 RD-Agent 迭代 SOTA 的前提）。

### 9.5 对 RD-Agent 使用的建议

1. **重视 feedback 的 `new_hypothesis`**：本轮 LLM 已建议"量价确认的动量、波动率调整收益、动量×波动率交互项"，这与 9.1 节建议一致，应让下一轮 Loop 沿此方向；
2. **多跑几轮**：RD-Agent 的价值在于迭代积累，SOTA 应随每轮 Loop 增长。当前仅 Loop_0，建议至少跑 5~10 轮观察 SOTA 是否提升；
3. **调整 hypothesis_gen 提示**：可在配置层把 proposal 提示偏向"量价联合/回归残差类"，避免系统反复生成纯价格动量；
4. **补单因子 IC**：修改/扩展 runner 让 `sub_results` 记录每个因子单独 IC，便于做归因（当前无法定位哪个因子拖后腿）。

### 10.2 指标口径说明

- **IC / Rank IC / ICIR**：由 qlib `SigAnaRecord` 计算，**组合口径**（非单因子），IC=预测信号与 next-day 真实收益的截面相关；
- **年化超额（含/不含成本）**：`PortAnaRecord` 输出，相对沪深300 基准；
- **信息比率 IR**：超额收益均值 / 超额收益标准差（年化）；
- **最大回撤**：组合净值曲线峰到谷的最大跌幅；
- **l2.train / l2.valid**：LightGBM 在 train/valid 段的 MSE（越低越好，但接近 1 说明拟合偏弱）。
